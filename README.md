# paddy-crop-disease-detection

Paddy Crop Disease Detection Using Machine Learning

About the Project
This project detects paddy leaf diseases using CNN and SVM.

Disease Classes
- Leaf Blast
- Brown Spot
- Hispa
- Healthy

Technologies Used
- Python
- CNN
- SVM
- OpenCV
- NumPy
- Tkinter

Results
CNN achieved 98% accuracy.
SVM achieved 40% accuracy.

How to Run
1. Install the required libraries.
2. Run PaddyDisease.py.
